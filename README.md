# Embedded Computing Resources

A reference collection of embedded and industrial computing platforms, maintained by [Aaronn Electronic GmbH](https://www.aaronn.de/).

Aaronn Electronic is a system integrator for embedded computing based in Puchheim near Munich, Germany, and has been working in the field since 1993. Use this page to compare form factors, find product information, and choose the right platform for your project.

## 1. Computer-on-Modules

Computer-on-Modules (COMs) are compact boards that hold the processor, memory and core interfaces. They plug onto a carrier board designed for your application.

## 4. How to Choose a Platform

1. Define your performance and power limits.
2. Pick a form factor (COM Express, SMARC, Qseven or OSM).
3. Check your I/O needs: Ethernet, USB, serial and display.
4. Check the operating temperature range and product lifecycle.
5. Decide between a standard system and a customized one.
